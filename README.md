# CodeAlpha_Basic-Network-Sniffer
# Network Traffic Packet Capture

## Project Overview
This project is developed using Python and Scapy to capture live network traffic packets. It displays important packet details such as Source IP, Destination IP, Protocol, Source Port, Destination Port, and Packet Summary.

## Features
- Live Packet Capture
- TCP, UDP, and ICMP Packet Detection
- Source and Destination IP Address
- Source and Destination Port Information
- Packet Summary Display
- Dynamic Interface Selection
- User-defined Packet Capture Count
- Packet Logging

## Technologies Used
- Python 3.12
- Scapy
- Npcap
- Windows 11

## Project Files
- Task1_Static_Packet_Capture.py – Basic packet capture program.
- Task2_Dynamic_Packet_Capture.py – Enhanced packet capture with dynamic interface selection and logging.

## Requirements
Install Scapy using:

```bash
pip install scapy
```

Install Npcap before running the program.

## How to Run

```bash
python Task1_Static_Packet_Capture.py
```

or

```bash
python Task2_Dynamic_Packet_Capture.py
```
